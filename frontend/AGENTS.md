# AGENTS — frontend

Эти правила применяются ко всем файлам в `frontend/` и дополняют корневой `AGENTS.md`.

## Стиль и компоненты
- Проект на React + TypeScript: используйте функциональные компоненты и хуки.
- Все пропсы, состояния и хендлеры типизируйте; избегайте `any`.
- Компоненты держите небольшими; общую логику выносите в хуки или утилиты.

## Стили и UI
- Стили задавайте через Tailwind-классы; условные классы формируйте с помощью `clsx`.
- Пользовательские тексты и UI-копирайт по умолчанию на русском языке, в соответствии с существующим интерфейсом.

## Работа с API
- Сетевые запросы выполняйте только через слой `src/api` или существующие клиентские утилиты.
- Не хардкодьте ключи, токены или конфигурацию окружения на фронтенде.

## Проверки
- Перед коммитом по возможности выполняйте `npm run build` или более узкую проверку и фиксируйте результат.
