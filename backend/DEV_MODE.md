# Dev-режим без Postgres

Если вы запускаете backend с SQLite (или иной БД), advisory-lock `pg_advisory_xact_lock`
отключается. Вместо него для неаутентифицированного режима используется повторная
проверка `Organization.id` в той же транзакции: если запись не появилась, создаётся
организация `Personal`; если их несколько — требуется явно указать `X-Org-ID`.
